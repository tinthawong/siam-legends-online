# ภาพ UI: กระเป๋า จอยสติ๊ก ปุ่มโจมตี

ไฟล์ทั้งหมดอยู่ที่ `art/ui/` พื้นหลังโปร่งใส เป็นภาพวาดความละเอียดสูง ย่อตอนแสดงผล (อย่าใช้โหมด pixelArt กับภาพกลุ่มนี้)

## จอยสติ๊ก
- `joystick-base.png`: ฐาน ตรงกลางเป็นกระจกโปร่งแสง
- `joystick-knob.png`: ลูกแก้ว วางกลางฐาน ลากได้ไม่เกินขอบกระจก (รัศมีกระจก ≈ 30% ของความกว้างฐาน)
- ปล่อยนิ้ว: ลูกแก้วดีดกลับกลาง
- แสดงทั้งมือถือและคอม (เดิมเฉพาะจอสัมผัส ผู้ใช้เปลี่ยนให้เหมือนกันทุกเครื่อง) มุมซ้ายล่าง ความกว้างประมาณ 28% ของด้านสั้นของจอ

## ปุ่มโจมตี
- `attack-button.png` ปกติ, `attack-button-pressed.png` ตอนกดค้าง (สลับภาพ ไม่ต้องย่อขยาย)
- มุมขวาล่าง ขนาดประมาณ 22% ของด้านสั้นของจอ
- ทำงานเหมือนการโจมตีปกติ: ตีเป้าหมายที่เลือกอยู่ ถ้าไม่มีเป้า เลือกมอนที่ใกล้ที่สุดในระยะ

## กระเป๋า
- ภาพ `inventory-panel.png` พิกัดทุกส่วนอยู่ใน `shared/data/inventory-layout.json` (พิกเซลของภาพเต็ม)
  ย่อภาพตอนแสดงผลแล้วคูณพิกัดด้วยสัดส่วนเดียวกัน
- ช่องไอเท็ม 24 ช่อง (`slots`) วาดติดอยู่ในภาพ เลื่อนแบบ scroll ไม่ได้
  ให้ใช้แบบหน้า: ปุ่ม `pageUp` / `pageDown` เปลี่ยนหน้าละ 24 ช่อง แถบเลื่อนในภาพแสดงว่าอยู่หน้าไหน
- ไอเท็มในช่อง: ไอคอนกลางช่อง จำนวนมุมขวาล่าง (ถ้ามากกว่า 1)
- แท็บ 5 อัน (`tabs`) กรองชนิดไอเท็ม เขียนชื่อทับด้วยโค้ด: ทั้งหมด / ใช้ได้ / อุปกรณ์ / วัตถุดิบ / เควส
- `moneyBar`: จำนวนเงิน (เบี้ย), `gemBar`: ยังไม่ใช้ ปล่อยว่าง
- ปุ่มล่าง 5 ปุ่ม (`navButtons`): bag = กระเป๋า (หน้านี้), consumables = ไปแท็บ "ใช้ได้",
  quest = รายการเควส, settings = ตั้งค่า, menu = เมนูรวม
  ปุ่มที่ยังไม่มีหน้าปลายทาง ให้กดแล้วไม่เกิดอะไร
- ปิดกระเป๋า: แตะนอกกรอบ หรือกดปุ่มกระเป๋าซ้ำ (คอม: คีย์ Alt+E แบบ Ragnarok)
