# แถบสถานะ (เลเวล HP SP EXP)

## ภาพกรอบ
ภาพอยู่ที่ `art/ui/hud/` ตำแหน่งช่องทั้งหมดอยู่ใน `shared/data/hud-layout.json` (พิกเซลของภาพเต็ม)
เป็นภาพวาดความละเอียดสูง ย่อตอนแสดงผล (อย่าใช้โหมด pixelArt)
- `status-frame.png` (653×187): กรอบสถานะ
  - `namePlate`: เขียน `Lv. xx` (ทอง) ตามด้วยชื่อ (ขาว)
  - `hpBar`, `spBar`: วาดแถบสีเติมกับตัวเลขในกรอบสี่เหลี่ยมนี้ ช่องว่างที่เหลือคือพื้นกรมท่าของภาพเอง
  - ขนาดแสดงผล: คอม กว้าง 320 px, มือถือ กว้าง 260 px (ย่อทั้งภาพตามสัดส่วน คูณพิกัดช่องด้วยสัดส่วนเดียวกัน)
- แถบ EXP แบบ 3 ท่อน: `exp-left.png`, `exp-mid.png`, `exp-right.png` (สูง 68 px)
  - ย่อทั้งสามท่อนให้สูงเท่ากับความสูงแถบที่ต้องการ (คอม 22 px, มือถือ 18 px)
  - วางปลายซ้ายชิดซ้าย ปลายขวาชิดขวา ยืดท่อนกลางเต็มช่องที่เหลือในแนวนอนเท่านั้น
  - ช่องเติมสี: เริ่มหลังขอบซ้าย `insetLeft`, จบก่อนขอบขวา `insetRight`, ที่ `y` สูง `h` (หน่วยของภาพเต็ม คูณสัดส่วนที่ย่อ)

## กรอบสถานะ
- บรรทัดบน: `Lv. 52` (ทอง ตัวหนา) ตามด้วยชื่อตัวละคร (ขาว)
- แถบ HP: สีแดงไล่เฉด ตัวเลข `HP ปัจจุบัน / สูงสุด` ชิดขวาในแถบ
- แถบ SP: สีฟ้าไล่เฉด ตัวเลข `SP ปัจจุบัน / สูงสุด` ชิดขวาในแถบ
- HP ต่ำกว่า 25%: แถบ HP กะพริบช้า ๆ
- ค่าลดลง: ส่วนที่หายไปค้างเป็นสีขาวครู่หนึ่งแล้วค่อยหดตาม (ผู้เล่นเห็นว่าเพิ่งโดนไปเท่าไหร่)
- ตำแหน่ง: คอม = มุมซ้ายล่าง เหนือแถบ EXP / มือถือ = มุมซ้ายบน (ล่างซ้ายเป็นที่ของจอยสติ๊ก)

## แถบ EXP
- ยาวเต็มความกว้างจอ ชิดขอบล่างสุด (เหนือขอบปลอดภัยของมือถือ) ใช้ภาพกรอบ 3 ท่อนด้านบน
- สีเติม: ทองไล่เฉด
- ข้อความกลางแถบ: `EXP ปัจจุบัน (xx.xx%)` ตัวเล็ก ขอบดำให้อ่านออกบนสีทอง
- ชี้เมาส์ (คอม) หรือแตะ (มือถือ) ที่แถบ: ขึ้นกล่องเล็ก `EXP : ปัจจุบัน / ที่ต้องใช้ [xx.xx%]` หายไปเองใน 3 วินาที
- เปอร์เซ็นต์ทศนิยม 2 ตำแหน่ง ปัดลง (ไม่ให้ขึ้น 100.00% ก่อนเลเวลขึ้นจริง)
- EXP ที่ต้องใช้ต่อเลเวล: จากตารางเลเวลที่ export จากตารางสมดุล
- เลเวลสูงสุด: แถบเต็ม ข้อความ `MAX`

## ได้ EXP / เลเวลขึ้น
- ได้ EXP: แถบเลื่อนเพิ่มแบบนุ่ม ๆ (0.3 วินาที) และตัวเลข `+EXP` ลอยขึ้นเหนือหัวตัวละครสีทอง
- เลเวลขึ้น: แถบวิ่งจนเต็ม → แวบสว่าง → กลับเป็นศูนย์แล้ววิ่งต่อด้วย EXP ที่เหลือ
  ตัวอักษร `LEVEL UP!` สีทองใหญ่กลางจอ 2 วินาที, แสงทองพุ่งขึ้นรอบตัวละคร (ผู้เล่นคนอื่นเห็นแสงด้วย)
  เลข `Lv.` ในกรอบสถานะเด้งขยายเล็กน้อย
  ถ้ามีแต้มค่าพลังว่าง ปุ่มหน้าต่างค่าพลังขึ้นจุดแดง (ตาม stat-system.md)
- เลเวลขึ้นหลายเลเวลในครั้งเดียว: แถบวิ่งเต็มทีละรอบ แต่ข้อความ LEVEL UP แสดงครั้งเดียว บอกเลเวลสุดท้าย

## ข้อมูลจาก server
- `stats` (มีอยู่แล้วใน stat-system.md) เพิ่ม: `level, exp, expNext, hp, hpMax, sp, spMax`
- `exp_gain {amount, exp, expNext, level}` ทุกครั้งที่ได้ EXP
- `level_up {level, ...ค่าใหม่}` ส่งให้ผู้เล่นทุกคนในแมพ (เพื่อเห็นแสง)
- HP/SP เปลี่ยน: ใช้ข้อความที่มีอยู่แล้วตอนโดนตี/ฟื้นเลือด

## ปุ่มเมนู 6 ปุ่ม
ภาพ `art/ui/hud/btn-*.png` (310×310 โปร่งใส ทุกปุ่มขนาดเท่ากัน)

| ภาพ | เปิด | คีย์ลัด (คอม) |
|---|---|---|
| btn-inventory | กระเป๋า | Alt+E |
| btn-equipment | อุปกรณ์ (ยังไม่มีระบบ: กดแล้วไม่เกิดอะไร) | Alt+Q |
| btn-quest | รายการเควส | Alt+U |
| btn-stats | หน้าต่างค่าพลัง | Alt+A |
| btn-map | แผนที่โลก (ยังไม่มีหน้า: กดแล้วไม่เกิดอะไร) | M |
| btn-settings | ตั้งค่า (ยังไม่มีหน้า: กดแล้วไม่เกิดอะไร) | Esc |

- คอม: เรียงแถวเดียวต่อจากขวาของกรอบสถานะ ปุ่มละ 44 px ห่างกัน 4 px ชิดขอบล่างของกรอบสถานะ
- มือถือ: เรียงแถวเดียวมุมขวาบน ปุ่มละ 38 px
- กด: ปุ่มย่อลงเหลือ 92% และสว่างขึ้นเล็กน้อยจนปล่อยนิ้ว
- ปุ่มที่ยังไม่มีหน้าปลายทาง: สีจางลง (ความทึบ 50%)
- จุดแดงมุมขวาบนของปุ่ม btn-stats เมื่อมีแต้มค่าพลังว่าง (ใช้แทนจุดแดงที่เขียนไว้ใน stat-system.md)
- ปุ่มล่างในหน้ากระเป๋า (ui-controls.md) ใช้เปิดหน้าเดียวกันกับปุ่มชุดนี้
