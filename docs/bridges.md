# สะพานและท่าเรือ

ภาพอยู่ที่ `art/props/bridges/` เป็นขนาดในเกมแล้ว ไม่ต้องย่อ (แต่ละภาพเป็นชิ้นเดียว ไม่ใช่ชิ้นต่อกัน)

| ชื่อ prop ในแมพ | ภาพ | ขนาด |
|---|---|---|
| bridge-main | `bridge-main-back.png` + `bridge-main-front.png` | 235×103 |
| bridge-foot | `bridge-foot-back.png` + `bridge-foot-front.png` | 235×103 |
| pier | `pier.png` | 72×146 |

ตำแหน่ง prop (x, y) ในผัง = กึ่งกลางขอบล่างของภาพ เหมือน prop อื่น
ภาพ back กับ front ของสะพานเดียวกันขนาดเท่ากัน วางที่ตำแหน่งเดียวกันซ้อนกันพอดี

## สะพานโค้ง (bridge-main, bridge-foot)
- **ชั้นหลัง (back):** พื้นสะพานกับราวด้านไกล วาดเหนือน้ำแต่ใต้ตัวละครทุกตัว
- **ชั้นหน้า (front):** ราวด้านใกล้กับเสา วาดเรียงความลึกตามขอบล่างของภาพ (y-sort แบบ prop ปกติ)
  ตัวละครบนสะพานจึงอยู่หลังราวหน้า ตัวละครที่อยู่ใต้สะพาน (เช่น บนท่าเรือ) อยู่หน้าราว
- **เดินได้:** แถวช่องที่อยู่ใต้เส้นเท้า เดินได้ตลอดความกว้างสะพาน แม้เป็นช่องน้ำ
  เส้นเท้า = ขอบบนของภาพ + 37 px
- **ความโค้ง:** ตัวละครบนสะพาน ยกภาพตัวละครขึ้นตามตำแหน่งแนวนอน (ตำแหน่งจริงบน server ไม่เปลี่ยน แค่วาด)
  `t = min(1, |x - กึ่งกลางสะพาน| / (ความกว้างภาพ × 0.37))`
  `ยกขึ้น = 16 × (1 - t²)` px  (กลางสะพานยกสูงสุด 16 px ปลายสะพานไม่ยก)
- ชื่อลอย แถบเลือด และตัวเลขความเสียหายของตัวละครยกขึ้นตามไปด้วย

## ท่าเรือ (pier)
- ภาพเดียว วาดใต้ตัวละครทุกตัว (เหมือนพื้น)
- **เดินได้:** ทุกช่องใต้พื้นท่าเรือ (ภาพกว้าง 72 px ตัดขอบซ้ายขวาข้างละ 12 px เป็นราว)
- ผู้เล่นใหม่เกิดที่ปลายท่าเรือ (จุด `start` ในผัง)

## ตรวจตอน build แมพ
- `build_map.py` ต้องทำช่องใต้สะพานและท่าเรือให้เดินได้ในตาราง walkable
- ภาพตัวอย่างแมพต้องวาดชั้นหลังและชั้นหน้าของสะพานถูกลำดับ
