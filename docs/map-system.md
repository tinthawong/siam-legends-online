# ระบบแมพ (Siam Legends Online)

แมพประกอบใน Tiled (mapeditor.org) บันทึกเป็น `.tmj` (JSON ของ Tiled)
แล้วแปลงเป็นไฟล์แมพของเกมที่ใช้ร่วมกันทั้ง client และ server

## ขนาด
- ช่องละ 32px, มุมมอง orthogonal (low top-down)
- บ้านปากอ่าว: 60 × 44 ช่อง (1920 × 1408 px) id แมพ `ban-pak-ao`

## โครงไฟล์
```
maps/
  siam.tiled-project          โปรเจกต์ Tiled (ผู้ใช้เปิดไฟล์นี้)
  tilesets/terrain.tsx        พื้น 5 แบบ สำหรับระบาย
  tilesets/block.tsx          ช่องทึบ 1 แบบ (สีแดงโปร่งแสง)
  tilesets/props.tsx          ของประดับทุกชิ้นจาก art/props/ (Collection of Images)
  ban-pak-ao.tmj              แมพ
shared/data/maps/ban-pak-ao.json   ไฟล์ที่เกมใช้ (สร้างจาก .tmj ด้วยสคริปต์)
```

## Tileset
- **terrain.tsx:** 6 ช่อง 32×32 ใช้ภาพย่อจาก `art/tiles/` (grass, sand, water, dirt, paddy) และช่องที่ 6 `forest` (ภาพต้นไม้ย่อจากชุดที่ 6)
  แต่ละช่องมี property `terrain` = ชื่อพื้น
  ภาพในนี้ใช้แค่ตอนระบายใน Tiled ในเกมวาดพื้นจริงเอง (ดู "การวาดพื้น")
- **block.tsx:** ช่องสีแดงโปร่งแสงช่องเดียว ใช้ระบายจุดที่เดินไม่ได้เพิ่มเอง
- **props.tsx:** ภาพของประดับทุกชิ้นขนาดเท่าในเกม (จาก props.json ของแต่ละชุด)
  แต่ละชิ้นมี property `solid` (bool) ตั้งค่าเริ่มต้นให้:
  - `false`: ดอกไม้, หญ้าสูง, เฟิร์น, เปลือกหอย, ปลาดาว, ก้อนหินแบน, ฟ่อนข้าว, ผักบุ้ง และของที่เล็กกว่าครึ่งช่อง
  - `true`: ที่เหลือทั้งหมด (บ้าน, ต้นไม้, ศาลา, โอ่ง, รั้ว, เรือ ฯลฯ)
  - สะพานปลา (pier) `false` และทำให้ช่องน้ำใต้สะพานเดินได้

## เลเยอร์ในแมพ (ชื่อต้องตรงนี้)
| เลเยอร์ | ชนิด | ใช้ทำอะไร |
|---|---|---|
| `ground` | Tile layer | ระบายพื้น ทุกช่องต้องมีพื้น |
| `block` | Tile layer | ช่องที่เดินไม่ได้เพิ่มเติม |
| `props` | Object layer | ของประดับ (Tile object) |
| `spawns` | Object layer | สี่เหลี่ยมจุดเกิดมอน property: `monster` (string), `count` (int) |
| `npcs` | Object layer | จุด (Point) property: `npc` (string เช่น npc_monk) |
| `start` | Object layer | จุด (Point) จุดเกิดผู้เล่น 1 จุด |
| `exits` | Object layer | สี่เหลี่ยมทางออกไปแมพอื่น property: `to` (id แมพ), `label` (ชื่อที่แสดง) |

## ช่องที่เดินไม่ได้ (ใช้กับ A* ฝั่ง server)
ช่องเดินไม่ได้ถ้าเข้าเงื่อนไขข้อใดข้อหนึ่ง:
1. พื้นเป็น `water` (ยกเว้นช่องใต้สะพานปลา) หรือ `forest`
2. มีช่องในเลเยอร์ `block`
3. อยู่ใต้ "ฐาน" ของ prop ที่ `solid = true`
   ฐาน = แถบล่างของภาพ กว้าง 70% ของภาพ (ตรงกลาง) สูง 1 ช่อง
   ถ้าภาพกว้างเกิน 3 ช่อง (เช่น บ้าน ต้นไทร) ฐานสูง 2 ช่อง
   ผู้เล่นจึงเดินผ่านหลังคาและพุ่มไม้ด้านบนได้ (เดินไปอยู่ข้างหลัง)

## การวาดพื้น (client)
- วาดพื้นทั้งแมพครั้งเดียวตอนโหลดลง RenderTexture แล้วใช้ภาพนั้นตลอด
- แต่ละช่องวาดลาย 64×64 จาก `art/tiles/` แบบต่อกันตามพิกัดโลก (ไม่เริ่มลายใหม่ทุกช่อง)
- **ขอบระหว่างพื้นต่างชนิด:** ลำดับชั้นจากล่างขึ้นบน `water < sand < paddy < dirt < grass`
  ชนิดที่ชั้นสูงกว่ากินเข้าไปในช่องข้างเคียง 4–8px เป็นขอบหยักแบบพิกเซล
  (ไม่ใช่ไล่สีเบลอ) สุ่มรูปขอบด้วย noise ที่คำนวณจากพิกัดช่อง
  ให้แมพหน้าตาเหมือนเดิมทุกครั้งที่โหลด
- ขอบน้ำฝั่งทรายมีเส้นฟองคลื่นสีขาวบาง ๆ 1–2px

## ป่า (พื้น `forest`)
- ในแมพระบายแค่ว่าช่องไหนเป็นป่า ไม่ต้องวางต้นไม้ทีละต้น ใต้ป่าวาดเป็นหญ้า
- ตอนวาดแมพ เติมต้นไม้จาก `art/props/set6/` ลงช่องป่า ช่องละ 2 ต้น ตำแหน่งสุ่มในช่อง
  (สุ่มจากพิกัดช่อง ให้ป่าหน้าตาเหมือนเดิมทุกครั้ง) พลิกซ้ายขวาสุ่มครึ่งหนึ่ง
- ต้นที่ใช้ในป่า: mango-tree, jackfruit-tree, tamarind-tree, rain-tree, round-tree,
  tall-forest-tree, indian-almond และต้นมีดอก (flame-tree, golden-shower) ราว 12%
  ต้นอื่นในชุด 6 (กล้วย, มะละกอ, หมาก, ลีลาวดี, ต้นไม้เล็ก, พุ่ม) ใช้วางเดี่ยวเป็น prop เท่านั้น
- ต้นไม้ในช่องป่าที่ไม่ติดช่องเดินได้เลย: รวมวาดเป็นภาพเดียวกับพื้น (ประหยัดเครื่อง)
  ต้นไม้ในช่องป่าที่ติดช่องเดินได้ (ริมป่า): วาดเป็น sprite แยก เรียงความลึกตาม y
  ตัวละครที่เดินชิดป่าจึงไปอยู่หลังต้นไม้ริมป่าได้ถูกต้อง
- ต้นไม้ริมป่าด้านบนของช่องเดินได้ยื่นทับขึ้นไปได้ แต่ป่าต้องไม่บังตัวละครที่ยืนบนช่องเดินได้เกินครึ่งตัว

## ทางออก
- เดินเข้าสี่เหลี่ยม `exits` แล้วย้ายไปแมพ `to` (ยังไม่มีแมพอื่น: ขึ้นข้อความ "เส้นทางนี้ยังไม่เปิด" แล้วดันผู้เล่นถอยกลับ 1 ช่อง)
- แสดงชื่อ `label` ลอยเหนือทางออกเมื่อผู้เล่นเข้าใกล้

## การวาด props และตัวละคร
- props, ผู้เล่น, มอน, NPC อยู่ชั้นเดียวกัน เรียงความลึกตามพิกัด y ของเท้า/ฐาน
  (ใครอยู่ต่ำกว่าบนจอ วาดทับคนที่อยู่สูงกว่า)
- รองรับการพลิกซ้ายขวา (flip) ที่ตั้งใน Tiled

## ไฟล์แมพของเกม: `tools/build_map.py`
อ่าน `.tmj` แล้วเขียน `shared/data/maps/<id>.json`:
```json
{
  "id": "ban-pak-ao", "width": 60, "height": 44, "tile": 32,
  "terrain": ["grass", "..."],
  "walkable": "สตริง 0/1 ยาว width*height",
  "props": [{ "name": "banyan", "x": 0, "y": 0, "flip": false }],
  "spawns": [{ "monster": "rice-crab", "count": 8, "x": 0, "y": 0, "w": 0, "h": 0 }],
  "npcs": [{ "npc": "npc_monk", "x": 0, "y": 0 }],
  "start": { "x": 0, "y": 0 },
  "exits": [{ "to": "thung-na", "label": "ทุ่งนาริมคลอง", "x": 0, "y": 0, "w": 0, "h": 0 }]
}
```
- เพิ่ม `npm run map` ให้รันสคริปต์นี้กับทุกแมพใน `maps/`
- ถ้าเจอปัญหาให้แจ้งเป็นภาษาไทยแล้วหยุด: ไม่มีเลเยอร์ที่ต้องมี, ช่องพื้นว่าง,
  ไม่มี `start`, จุดเกิดมอนหรือ NPC อยู่บนช่องเดินไม่ได้, ชื่อมอน/NPC ไม่มีในเกม
- ตำแหน่ง NPC ใน `npcs.json` ให้ใช้ค่าจากแมพแทน

## ฝั่ง server
- โหลดแมพจาก JSON, ใช้ `walkable` กับ A*
- มอนเกิดแบบสุ่มภายในสี่เหลี่ยม spawn เฉพาะช่องที่เดินได้ รักษาจำนวนให้ครบ `count`
  มอนเดินเล่นอยู่ในสี่เหลี่ยมของตัวเอง
- ผู้เล่นใหม่และผู้เล่นที่ตายเกิดที่ `start`

## ร่างแรกของบ้านปากอ่าว
สร้าง `maps/ban-pak-ao.tmj` ให้ครบทุกเลเยอร์ ตามหลักการจัดวางแมพใน CLAUDE.md
(โซน, ถนนดินเส้นหลักเชื่อมทุกโซน, ของขึ้นเป็นกลุ่ม, ต้นไม้/ไผ่เป็นกรอบขอบแมพ)
- ทะเลอยู่ด้านใต้ ชายหาดทรายเป็นแนวต่อจากทะเล
- เพิ่มสระน้ำเล็กในโซนนาข้าว มีบัวรอบสระ (ที่อยู่ของกบบัว)
- spawns: ปูนา (rice-crab) ในนาข้าว, ปูแดง (red-crab) บนชายหาด,
  กบบัว (lotus-frog) รอบสระ, หุ่นไล่กา (scarecrow) ปลายนาข้าวฝั่งไกลจากหมู่บ้าน
- npcs: หลวงพี่ (npc_monk) หน้าศาลา, ผู้ใหญ่ทองดี (npc_headman) ลานกลาง
- start: ถนนหน้าประตูหมู่บ้าน
- ทำภาพตัวอย่างแมพทั้งแผ่น `maps/preview-ban-pak-ao.png` ไว้ดูโดยไม่ต้องเปิดเกม
