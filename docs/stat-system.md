# ระบบค่าพลัง (แบบ Ragnarok)

server เป็นผู้คำนวณทุกค่า client แสดงผลอย่างเดียว

## ค่าพลังหลัก 6 ค่า
| ค่า | ชื่อไทย | มีผลกับ |
|---|---|---|
| STR | พลัง | ATK กายภาพ (ระยะประชิด), น้ำหนักที่แบกได้ |
| AGI | ว่องไว | ความเร็วโจมตี, FLEE (หลบ) |
| VIT | อึด | HP สูงสุด, ฟื้น HP, DEF เสริม |
| INT | ปัญญา | MATK, SP สูงสุด, ฟื้น SP, MDEF เสริม |
| DEX | แม่นยำ | HIT, ATK ระยะไกล, ความเร็วโจมตีเล็กน้อย, ร่ายเวทเร็วขึ้น |
| LUK | โชค | คริติคอล, หลบสมบูรณ์, ATK เล็กน้อย |

- ตัวละครใหม่: ทุกค่าเริ่มที่ 5 (รวม 30 แบบ Ragnarok) แต้มว่าง 0
- ค่าสูงสุดต่อค่า: 150 (เกมไปถึงเลเวล 200+ ถ้าตันที่ 99 แบบ Ragnarok แต้มจะเหลือเยอะเกิน)

## แต้มค่าพลัง
- ได้ทุกครั้งที่เลเวลขึ้น: `floor(เลเวลใหม่ / 5) + 3` แต้ม
- ราคาเพิ่มค่าจาก x เป็น x+1: `floor((x - 1) / 10) + 2` แต้ม (ยิ่งสูงยิ่งแพง)
- ผู้เล่นกด + เอง เพิ่มทีละ 1 หรือกดค้างเพิ่มต่อเนื่อง ลดคืนไม่ได้
- ล้างแต้ม: ยังไม่ทำในรอบนี้

## ค่าที่คำนวณจากค่าหลัก (Lv = เลเวลตัวละคร)
| ค่า | สูตร |
|---|---|
| ATK กายภาพ (ประชิด) | `STR + floor(STR/10)^2 + floor(DEX/5) + floor(LUK/5)` + ATK อาวุธ |
| ATK ระยะไกล | `DEX + floor(DEX/10)^2 + floor(STR/5) + floor(LUK/5)` + ATK อาวุธ |
| MATK | ต่ำสุด `INT + floor(INT/7)^2` สูงสุด `INT + floor(INT/5)^2` สุ่มระหว่างสองค่า |
| HIT | `Lv + DEX` |
| FLEE | `Lv + AGI` |
| หลบสมบูรณ์ (%) | `1 + LUK / 10` |
| คริติคอล (%) | `1 + LUK * 0.3` |
| HP สูงสุด | `(40 + Lv * 12) * (1 + VIT / 100)` |
| SP สูงสุด | `(10 + Lv * 2) * (1 + INT / 100)` |
| DEF เสริม (ลบตรง) | `floor(VIT / 2)` |
| MDEF เสริม (ลบตรง) | `INT` |
| ช่วงเวลาระหว่างการโจมตี (ms) | `1200 * (1 - (AGI * 4 + DEX) / 1000)` ต่ำสุด 300 |
| เวลาร่าย | `เวลาร่ายพื้นฐาน * (1 - DEX / 150)` ต่ำสุด 0 |
| ฟื้น HP ทุก 3 วินาที | `ceil(5% ของ HP สูงสุด + 1 + floor(VIT / 5) + floor(HP สูงสุด / 200))` เดิน/ต่อสู้ได้ครึ่งหนึ่ง (ผู้ใช้ขอให้เร็วขึ้น) |
| ฟื้น SP ทุก 3 วินาที | `ceil(5% ของ SP สูงสุด + 1 + floor(INT / 6) + floor(SP สูงสุด / 100))` เดิน/ต่อสู้ได้ครึ่งหนึ่ง · ฟื้นที่จุดเกิด = HP/SP เต็ม |
| น้ำหนักแบกได้ | `2000 + STR * 30` |

สูตร HP/SP ใช้กับทุกคนไปก่อน ตอนมีอาชีพค่อยเพิ่มตัวคูณตามอาชีพ

## การโจมตีโดน/พลาด
- โอกาสโดน (%) = `80 + HIT ผู้ตี - FLEE ผู้โดน` จำกัดอยู่ระหว่าง 5 ถึง 95
- **ผู้เล่นตีมอนไม่พลาด** ยกเว้นมอนเลเวลสูงกว่าผู้เล่นตั้งแต่ 30 เลเวลขึ้นไป จึงใช้สูตรข้างบน (`MISS_LEVEL_GAP` ใน shared/constants.ts) มอนตีผู้เล่นยังใช้สูตรข้างบนเสมอ
- HP มอนในตารางสมดุลคิดจากดาเมจเฉลี่ยของสายตีเลเวลเท่ามอน × ตีกี่ทีตาย (tools/mob_hp_from_build.py)
- ถ้าโดน สุ่มหลบสมบูรณ์ของผู้โดนอีกรอบ (เฉพาะผู้เล่น)
- คริติคอล: สุ่มจากค่าคริติคอลของผู้ตี ถ้าติด โดนแน่นอนและไม่หัก DEF

## สูตรความเสียหาย (แบบ Ragnarok ก่อน Renewal)
- กายภาพ: `ATK * สุ่ม(0.9 ถึง 1.1) * (1 - DEF เกราะ / 100) - DEF เสริม` อย่างน้อย 1
- เวท: `MATK * (1 - MDEF เกราะ / 100) - MDEF เสริม` อย่างน้อย 1
- คริติคอล: `ATK * 1.4` ไม่หัก DEF ทั้งสองแบบ
- DEF เกราะ / MDEF เกราะ เป็นเปอร์เซ็นต์ (มาจากอุปกรณ์ ตอนนี้ยังไม่มีอุปกรณ์ = 0)

## ค่าพลังของมอน
เพิ่มคอลัมน์ในตารางสมดุลชีต "มอน" แล้ว export ลง monsters.json:
| ค่า | สูตรเริ่มต้น (ปรับรายตัวได้ด้วยตัวคูณแบบ HP) |
|---|---|
| AGI | `floor(Lv * 0.6)` |
| DEX | `floor(Lv * 0.8)` |
| HIT | `Lv + DEX` |
| FLEE | `Lv + AGI` |
| DEF (%) | `min(40, floor(Lv * 0.3))` |
| DEF เสริม | `floor(Lv * 0.5)` |
| MDEF (%) | `min(30, floor(Lv * 0.2))` |
- มอนไม่มีคริติคอลและไม่หลบสมบูรณ์
- ATK ของมอนใช้ค่าที่มีอยู่แล้วในตาราง

## ตารางสมดุล
- เพิ่มชีต "สายเลี้ยงตัว" คิดค่าพลังของผู้เล่นแต่ละเลเวล 3 แบบ: สายตี (STR/DEX), สายหลบ (AGI/STR), สายอึด (VIT/STR)
  สมมติว่าแจกแต้มเท่ากันทุกเลเวลตามสัดส่วนของสาย
- คอลัมน์ "ตีกี่ทีตาย" ในชีตมอน ให้คำนวณจากสายตีที่เลเวลเท่ามอน ด้วยสูตรในไฟล์นี้ (รวมโอกาสโดน)
- เพิ่มคอลัมน์ "มอนตีกี่ทีผู้เล่นตาย" คิดจากสายตีเหมือนกัน
- ถ้ามอนตัวไหน "ตีกี่ทีตาย" ต่างจากเดิมมาก ให้รายงานผม อย่าปรับตัวคูณเอง

## ฐานข้อมูล
migration ใหม่: เพิ่มคอลัมน์ในตาราง character
`str, agi, vit, int, dex, luk` (ค่าเริ่มต้น 5) และ `stat_points` (ค่าเริ่มต้น 0)
ตัวละครที่มีอยู่แล้ว: ให้แต้มย้อนหลังตามเลเวลปัจจุบัน

## ข้อความ WebSocket
- client → server: `stat_add {stat, amount}`
- server → client: `stats {ค่าหลัก, แต้มว่าง, ค่าที่คำนวณทั้งหมด}` ส่งตอนเข้าเกม เลเวลขึ้น และเพิ่มแต้ม
- server ตรวจทุกครั้ง: แต้มพอ, ไม่เกิน 150, ชื่อค่าถูกต้อง

## หน้าต่างค่าพลัง
- ปุ่มเปิดบนจอ (มือถือ) และคีย์ลัด Alt+A (คอม) แบบ Ragnarok
- ซ้าย: 6 ค่าหลัก แต่ละแถวมี: ค่าที่อัปเอง, ช่องโบนัสสีเหลือง (เช่น `+2` จากอุปกรณ์ ตอนนี้ยังไม่มีอุปกรณ์ ให้ว่างไว้),
  ราคาแต้มของขั้นถัดไป และปุ่ม + (สีเทาถ้าแต้มไม่พอ)
  ค่าที่ใช้คำนวณทุกสูตร = ค่าที่อัปเอง + โบนัส
- ขวา 10 ช่อง แสดงแบบ Ragnarok:
  | ช่อง | แสดงเป็น |
  |---|---|
  | ATK | ค่าเดียว |
  | MATK | `ต่ำสุด ~ สูงสุด` |
  | HIT | ค่าเดียว |
  | CRITICAL | เปอร์เซ็นต์ ทศนิยม 1 ตำแหน่ง |
  | MAX HP | ค่าเดียว |
  | DEF | `DEF เกราะ + DEF เสริม` เช่น `0 + 2` |
  | MDEF | `MDEF เกราะ + MDEF เสริม` |
  | FLEE | `FLEE + หลบสมบูรณ์` เช่น `17 + 1.1` |
  | ASPD | ตัวเลขแบบ Ragnarok: `200 - (ช่วงเวลาระหว่างการโจมตี ms / 20)` ทศนิยม 1 ตำแหน่ง |
  | MAX SP | ค่าเดียว |
- แตะหรือชี้ที่ช่องไหน ขึ้นคำอธิบายสั้น ๆ ภาษาไทยว่าค่านั้นทำอะไร และค่าหลักตัวไหนเพิ่มค่านี้
- ล่าง: แต้มว่าง
- มีแต้มว่างเหลือ: ปุ่มเปิดหน้าต่างมีจุดแดงเตือน
- ธีมรักทองแบบหน้าล็อกอิน ใช้ได้ทั้งมือถือและคอม
