# ขนาดแมพและตาราง (ใช้แทนตัวเลขเดิมใน map-system.md)

| | ค่า |
|---|---|
| แมพใน Tiled | 30 × 22 ช่อง, ช่องละ 64 × 64 px |
| ขนาดแมพจริง | 1920 × 1408 px (เท่าเดิม) |
| ตารางเดินได้ / A* | ยังเป็นช่องละ 32 px (60 × 44 ช่อง) |

- ช่องภาพ 64 px หนึ่งช่อง = ช่องเดิน 32 px สี่ช่อง (2 × 2)
  ตอน build แมพ แปลงพื้นจากช่อง 64 เป็นตารางเดิน 32 (ช่องน้ำ/ป่า 64 → เดินไม่ได้ทั้ง 4 ช่อง)
  แล้วค่อยหักฐานของ prop และเพิ่มพื้นไม้ท่าเรือ/สะพานที่ระดับ 32 px เหมือนเดิม
- ตำแหน่ง props, decks, npcs, spawns, exits, entries, start ในผังเป็นพิกเซล ไม่ต้องแก้
- ผัง `maps/*.layout.json` แปลงเป็น 30 × 22 แล้ว (`"tile": 64`, `"walkTile": 32`)
- tileset ใน Tiled ทั้งหมดใช้ช่อง 64 × 64:
  - `terrain.tsx` ทำจากลายพื้น 64 × 64 ใน `art/tiles/` โดยไม่ต้องย่อ
  - `shore-tiles-64.png` (ชายฝั่ง 4 ทิศ) และ tileset อื่นที่ตัดด้วย `tools/slice_tileset.py --size 64`
- ตอนวาดพื้นในเกม ใช้ลาย 64 × 64 ตามขนาดจริง ไม่ย่อ
- ถ้าสร้าง `.tmj` ไปแล้วด้วยช่อง 32 ให้สร้างใหม่จากผังที่แปลงแล้ว
